# Network Programming in C

This repository is meant to organize my practical studies of programming in C with a focus on networking. It's still under construction — the code here reflects my learning process, not final or optimized solutions.

## Objective

Practicing fundamentals of network sockets, protocols, and communication over computer networks using pure C, as part of my roadmap in offensive security.

## Content

Each file here corresponds to one exercise or specific concept (sockets, TCP/UDP, client-server communication, packet parsing, etc). There's no fixed structure yet — it'll evolve as I progress.
